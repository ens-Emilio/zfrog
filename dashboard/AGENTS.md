# Dashboard (SPA)

Vite + TanStack Router, sem SSR. `routeTree.gen.ts` é gerado pelo plugin Vite — não editar.

- `npm run dev` — Vite na porta 5173
- `npm run build` — bundle estático em `dist/`
- `npm run typecheck` / `npm run lint`

Env: `VITE_API_URL` (URL que o browser alcança), `VITE_WS_URL` (opcional).
